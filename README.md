# Методички по русскому — сайт-магазин (черновик)

Пробный сайт для продажи методичек по русскому языку. Собран на React + Vite
на основе дизайн-системы сайтов для репетиторов. Все тексты и цены — заглушки.

## Что уже есть

- **Главная** — первый экран, преимущества, бестселлеры, наборы, об авторе,
  кому подойдёт, как купить, отзывы, вопросы.
- **Каталог** — 12 методичек, фильтр по категориям и переключение вида
  «сеткой / списком».
- **Как купить** — шаги, способы оплаты, получение материалов, гарантии.
- **Отзывы**, **Вопросы**, **Контакты**.
- **Оплата Prodamus** — кнопка «Купить» открывает платёжное окно
  «Единое окно» (режим `beauty`). Сейчас подключена демонстрационная
  страница, реальные деньги не списываются.

## Запуск

```bash
npm install
npm run dev
```

## Полезные команды

```bash
npm run lint     # проверка кода
npm run build    # сборка в dist/
npm run preview  # посмотреть собранную версию
```

## Где что лежит

```
src/
  content/site.js        все тексты, цены и методички — правится без кода
  lib/prodamus.js        подключение оплаты Prodamus
  components/guide/      карточка, обложка, кнопка «Купить», наборы
  components/ui/         общие элементы: кнопка, секция, аккордеон, отзыв
  components/layout/     шапка, подвал, меню
  pages/                 страницы сайта
  styles/                дизайн-токены и стили
```

## Подключение боевого Prodamus

В `src/lib/prodamus.js` заменить:

```js
export const PRODAMUS_DOMAIN = 'demo.payform.ru' // → сабдомен платёжной страницы
export const PRODAMUS_DEMO = 1                   // → 0 для реальной оплаты
```

## Что дальше

Заполнить реальные тексты, цены и обложки, уточнить состав каталога,
подключить боевой аккаунт Prodamus.
